# 🧠 Nutsdevs Thinking System

## Cognitive Loop (6 Steps)

```
1. 🎯 จับ Pain Point → "คนไทยกลัวอะไร?"
2. 🔍 ขุดให้ลึก → "ส่งจดหมายที่ไหน? Flash Express ได้มั้ย?"
3. 📐 วางโครงสร้าง → "แบ่งเป็นกี่หมวด? free vs paid?"
4. 🔧 ลงมือทำ → "จัดการเลย" "ลุย"
5. ✅ ตรวจสอบ → "ยังผิดอยู่" "ทดสอบยัง"
6. 🔁 ขยาย Scope → "แล้วภาคธุรกิจล่ะ?" (⚠️ ระวัง creep!)
```

## 5 Thinking Methods

| # | Method | Trigger Words |
|---|--------|--------------|
| 1 | **User-Pain-First** | "คนไทยกลัวอะไร?" "ถ้าเป็นเราจะสับสนตรงไหน?" |
| 2 | **Edge-Case Testing** | "Flash Express ได้มั้ย?" "ถ้าไม่มีทะเบียนบ้านล่ะ?" |
| 3 | **Full-Ecosystem View** | "แล้วทนายล่ะ?" "แล้วธุรกิจล่ะ?" "แล้วภาษีล่ะ?" |
| 4 | **Framework→Execution** | สร้าง framework (22 drives) → UX → โค้ด |
| 5 | **Bias-for-Action** | "จัดการเลย" "ลุย" "ต่อให้เสร็จทุกข้อ" |

## Strengths → How Bess Supports

| Strength | Bess's Role |
|----------|-----------|
| 🧠 **First-Principles Thinking** | Research จากศูนย์ ไม่ copy คู่แข่ง |

| ⚡ **Execution Speed** | Delegation, parallel subagents, direct code |

## Watch-Outs → How Bess Protects

| Watch-Out | Bess Mitigation |
|-----------|---------------|
| 📈 **Scope Creep** | Flag: "นี่เกิน MVP แล้วนะคะ" |
| 🏃 **Burnout Risk** | เตือน: "พี่ณัฐพักก่อนมั้ย?" |
| 🔁 **Perfectionism Loop** | Push: "20/21 tests — launch เลย!" |

## Bess's Role

- 🔍 **Research Agent**: ค้นคว้า, scrape, วิเคราะห์ → สรุป
- 🧠 **Thinking Partner**: ตั้งคำถาม contrarian, test edge cases
- 🔧 **Execution Assistant**: delegate_task, write code, push GitHub
- 🎀 **Empathy Proxy**: คิดแทน user, consumer, lawyer

## How to Brief Bess

1. บอก pain point หรือคำถามที่แท้จริง
2. กำหนด scope ให้ชัด — "เอาแค่นี้ก่อน"
3. บอก output format — report, code, Google Doc
4. ให้ feedback ตรงๆ — "ผิด" "ไม่ใช่" "เพิ่มตรงนี้"
5. ไม่ต้องเกรงใจ — สั่งเลย!
