## 1. 🛡️ ต้องการความอยู่รอดและความปลอดภัย (Survival & Safety)

> **"ชีวิตต้องไม่พังก่อนเรื่องอื่น"**

### สิ่งที่ต้องการ
- มีเงินพอใช้, มีบ้าน, มีอาหาร, มีงาน
- ไม่ถูกไล่ออก, ไม่ถูกโกง, ไม่เสี่ยงคดี, ไม่เสียทรัพย์
- สุขภาพไม่ทรุด, ครอบครัวปลอดภัย
- มีเงินสำรอง, มีแผนรองรับเหตุร้าย

### ลักษณะที่สังเกตได้
- ถามเรื่องความเสี่ยงบ่อย — "ถ้าเกิด...แล้วจะทำยังไง?"
- ไม่ชอบความไม่แน่นอน — ขอ guarantee, warranty
- ตัดสินใจช้า — ต้องคิดให้รอบคอบทุกมุม
- ต้องการหลักฐาน เอกสาร และการรับประกัน
- ยอมเสียโอกาสบางอย่างเพื่อรักษาความมั่นคง
- ชอบบริษัทใหญ่ หน่วยงานรัฐ หรือแบรนด์ที่น่าเชื่อถือ

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "มีรับประกันไหม?" | กลัวเสียเงินแล้วไม่ได้อะไร |
| "ถ้าไม่ได้ผลจะคืนเงินไหม?" | ต้องการ safety net |
| "ขอลองก่อนได้ไหม?" | ลดความเสี่ยงก่อน commit |
| "บริษัทนี้อยู่มากี่ปีแล้ว?" | เช็คความน่าเชื่อถือ |
| "มีใครเคยใช้แล้วเป็นยังไงบ้าง?" | ต้องการ social proof ประกอบ |
| "ถ้าฟ้องแล้วแพ้จะเสียอะไรอีกไหม?" | ประเมิน worst-case scenario |

### สถานการณ์ตัวอย่าง
> **สมศรี อายุ 45** ถูกนายจ้างเลิกจ้างกะทันหัน มีเงินเก็บพออยู่ได้ 3 เดือน มีลูกเรียนอยู่ 2 คน — เธอไม่ได้อยาก "ได้เงินเพิ่ม" แต่ต้องการ "ความมั่นคง" — รู้ว่าต้องทำอะไรให้ชีวิตไม่พัง

### ด้านมืด
- กลัวการเปลี่ยนแปลง → ปฏิเสธโอกาสดีๆ
- ยึดติดกับสิ่งที่คุ้นเคย → ไม่กล้าลงทุน
- ตัดสินใจช้าเกินไป → เสียโอกาส

## 2. 💰 ต้องการผลประโยชน์และความคุ้มค่า (Benefit & Value)

> **"ฉันได้อะไรจากเรื่องนี้?"**

### สิ่งที่ต้องการ
- กำไรมากขึ้น, ลดต้นทุน, ได้ราคาพิเศษ
- ได้ของแถม, ได้สิทธิ์ก่อนคนอื่น, ได้ข้อมูลวงใน
- ได้โอกาสทางธุรกิจ, ใช้แรงน้อยแต่ได้ผลมาก
- ผลตอบแทนที่วัดได้ — ไม่ใช่แค่คำพูดสวยๆ

### ลักษณะที่สังเกตได้
- ชอบต่อรอง — "ลดได้อีกไหม?"
- ถามเรื่องราคาและผลตอบแทนเป็นอย่างแรก
- เปรียบเทียบหลายเจ้า — เปิด 10 tabs เทียบราคา
- มองทุกความสัมพันธ์ในแง่การแลกเปลี่ยน
- สนใจตัวเลขมากกว่าคำพูดสวยงาม ("ROI เท่าไหร่?")
- ให้ความร่วมมือเมื่อเห็นประโยชน์ชัดเจน

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "คุ้มไหม?" | เปรียบเทียบ cost/benefit |
| "ถ้าซื้อ 2 อันลดกี่เปอร์เซ็นต์?" | ต้องการ deal ที่ดีกว่า |
| "คู่แข่งให้ราคาถูกกว่านะ" | ใช้ราคาเป็นอาวุธต่อรอง |
| "มีของแถมอะไรบ้าง?" | มองหา extra value |
| "ระยะยาวแล้วถูกกว่าไหม?" | คิดแบบ ROI |
| "ถ้าผมแนะนำลูกค้ามาให้ มี commission ไหม?" | มองทุกอย่างเป็น deal |

### สถานการณ์ตัวอย่าง
> **คุณธนา อายุ 38** เจ้าของร้านอาหาร — กำลังเลือกซื้อระบบ POS — ไม่สนว่ายี่ห้ออะไร สนแค่ว่า "อันไหนถูกสุด ใช้ได้นานสุด ซ่อมถูกสุด" — เขาพร้อมเปลี่ยนใจทันทีถ้ามีเจ้าอื่นให้ deal ดีกว่า

### ด้านมืด
- เห็นแก่ตัว — ใช้คนแล้วทิ้งเมื่อหมดประโยชน์
- ฉวยโอกาส — เอาเปรียบเมื่ออีกฝ่ายไม่ทันระวัง
- ไม่มีความภักดี — พร้อมเปลี่ยนไปหาใครก็ตามที่ให้มากกว่า

## 3. 🌟 ต้องการการยอมรับและคำชื่นชม (Recognition & Praise)

> **"ฉันมีคุณค่า และคนอื่นมองเห็นคุณค่าของฉัน"**

### สิ่งที่ต้องการ
- คำชม, การยอมรับ, การถูกมองเห็น
- ได้รับเครดิตในผลงาน, ชื่ออยู่ในรายชื่อคนสำคัญ
- มีคนกล่าวถึงในแง่ดี, ได้รับรางวัล
- เป็นที่รู้จักในวงการ, มี followers

### ลักษณะที่สังเกตได้
- ชอบแชร์ความสำเร็จบนโซเชียล
- ถามว่า "คุณคิดยังไงกับผลงานผม?"
- มีความสุขเวลาได้รับคำชม — หน้าแดง, ยิ้ม, ตาลุกวาว
- เสียใจมากเวลาโดนเมินหรือไม่มีใครสังเกต
- ทำงานหนักขึ้นเมื่อมีคนดู — "audience effect"
- อ่อนไหวกับ feedback — ทั้งบวกและลบ

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "มีใครเห็นที่ผมทำไหม?" | ต้องการ visibility |
| "คุณคิดว่าผมทำได้ดีไหม?" | ต้องการ validation |
| "ทำไมไม่เห็นมีใครขอบคุณเลย?" | รู้สึก undervalued |
| "ผมทำคนเดียวแท้ๆ แต่เจ้านายได้เครดิต" | ต้องการ credit |
| "แชร์ให้ผมหน่อยนะ" | อยากให้คนเห็น |
| "เขาชมผมเมื่อกี้!" (เล่าให้เพื่อนฟังต่อ) | ดีใจที่ถูก recognize |

### สถานการณ์ตัวอย่าง
> **น้องมินท์ อายุ 25** Graphic Designer — ทำงาน OT 3 คืนเพื่อส่งงานก่อน deadline — เจ้านายส่งอีเมลชมสั้นๆ แค่ "งานสวยมาก ขอบใจ" — น้องมินท์แคปหน้าจอเก็บไว้ดูเวลาเหนื่อย — เธอไม่ได้อยากได้เงินเพิ่ม แต่ "อยากให้ใครสักคนเห็นว่าเธอทำได้ดี"

### ด้านมืด
- ทำงานเพื่อคำชม ไม่ใช่เพื่อคุณภาพ → งานฉาบฉวย
- อ่อนไหวเกินไปเมื่อโดนวิจารณ์ → พังเมื่อเจอ negative feedback
- ติด validation จากคนอื่น → ไม่มีความสุขถ้าไม่มีใครชม

## 4. 👑 ต้องการอำนาจและการควบคุม (Power & Control)

> **"ฉันต้องเป็นคนกำหนดทิศทางเอง"**

### สิ่งที่ต้องการ
- อำนาจในการตัดสินใจ, ควบคุมทรัพยากร, บริหารคน
- มีอิสระในการกำหนดนโยบาย, เป็นผู้นำ
- ไม่ถูกบังคับ, ไม่ถูกสั่ง, ไม่ตกเป็นเบี้ยล่าง
- มีสิทธิ์ขาดในเรื่องสำคัญ

### ลักษณะที่สังเกตได้
- ชอบเป็นคนพูดคนสุดท้ายในการประชุม
- ไม่ชอบให้ใครมาสั่ง — "คุณไม่ต้องมาบอกผม"
- ชอบตำแหน่งที่มีอำนาจ — CEO, Director, Head of...
- ใช้คำว่า "ผมตัดสินใจ", "ผมสั่ง", "ผมจัดการเอง"
- หงุดหงิดเมื่อรู้สึกว่าเสียการควบคุม — "นี่มันเรื่องของผมนะ"
- ชอบ competition — อยากชนะ อยากเก่งกว่าคนอื่น

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "ขอตัดสินใจเอง" | ต้องการ autonomy |
| "อย่ามายุ่งเรื่องของผม" | ปกป้อง territory |
| "ให้ผมจัดการเอง" | อยากคุมสถานการณ์ |
| "ใครเป็นคนสั่ง?" | ต้องการรู้ hierarchy |
| "ผมมีอำนาจตัดสินใจเรื่องนี้" | ยืนยัน authority |
| "ถ้าผมเป็นคนคุม ผมจะทำแบบนี้" | อยากมี control |

### สถานการณ์ตัวอย่าง
> **คุณวิชัย อายุ 50** ผู้บริหาร — ถูก board สั่งให้เปลี่ยน strategy — เขาโกรธมาก ไม่ใช่เพราะ strategy แย่ แต่เพราะ "ไม่มีใครถามผมเลย" — ความต้องการที่แท้จริงคือ "การมีส่วนร่วมในการตัดสินใจ" = control

### ด้านมืด
- เผด็จการ — ไม่ฟังใคร, micromanage
- ก้าวร้าว — ใช้กำลังหรืออำนาจข่ม
- หวาดระแวง — กลัวเสียอำนาจ → ทำลายคู่แข่ง

## 5. 🤝 ต้องการความเป็นพวกพ้อง (Belonging & Connection)

> **"ฉันอยากมีกลุ่ม มีคนเข้าใจ มีที่ยืน"**

### สิ่งที่ต้องการ
- เพื่อน, ครอบครัว, ชุมชน, สังคม
- รู้สึกว่ามีคนรออยู่, มีกลุ่มที่ยอมรับ
- ไม่อยากโดดเดี่ยว, มีคนเข้าใจ
- มีคนแชร์ประสบการณ์เดียวกัน

### ลักษณะที่สังเกตได้
- ชอบเข้ากลุ่ม — LINE group, FB group, community
- พูดถึง "พวกเรา" บ่อย — "ทีมเรา", "กลุ่มเรา"
- ถามว่า "มีใครเป็นเหมือนกันไหม?"
- แชร์เรื่องส่วนตัวกับคนที่ไว้ใจ
- เสียใจมากเวลาโดนปฏิเสธจากกลุ่ม
- เปลี่ยนพฤติกรรมเพื่อให้เข้ากับกลุ่ม — conformity

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "มีกลุ่มให้เข้าไหม?" | อยากมี community |
| "มีใครรู้สึกเหมือนผมไหม?" | ต้องการ validation จากกลุ่ม |
| "ผมไม่อยากทำงานคนเดียว" | ต้องการเพื่อนร่วมทีม |
| "กลุ่มเรา..." | ระบุตัวตนกับกลุ่ม |
| "คิดถึงวันเก่าๆ ที่เราทำงานด้วยกัน" | โหยหาความเป็นพวกพ้อง |
| "เขาลบเพื่อนผม" | เสียใจที่ถูกตัดจากกลุ่ม |

### สถานการณ์ตัวอย่าง
> **น้องฟ้า อายุ 22** — First Jobber — เพิ่งย้ายมาทำงานที่กรุงเทพคนเดียว — เธอไม่ได้เหงาเพราะไม่มีเพื่อน แต่เหงาเพราะ "ไม่มีใครที่เข้าใจชีวิตเด็กต่างจังหวัดแบบเธอ" — สิ่งที่เธอต้องการคือ community ของคนที่ผ่านประสบการณ์เดียวกัน

### ด้านมืด
- ลด standards เพื่อให้เข้ากลุ่มได้ → ทำอะไรก็ได้เพื่อไม่ถูกทิ้ง
- กลัวการถูกปฏิเสธ → ไม่กล้าเสนอความเห็นต่าง
- พึ่งพากลุ่มมากเกินไป → สูญเสียตัวตน

## 6. 🕊️ ต้องการอิสระและเสรีภาพ (Autonomy & Freedom)

> **"ฉันจะใช้ชีวิตในแบบของฉัน"**

### สิ่งที่ต้องการ
- อิสระในการเลือก, อิสระทางเวลา, อิสระทางความคิด
- ไม่ถูกบังคับ, ไม่มีใครมาควบคุม
- Flexible hours, remote work, เป็นนายตัวเอง
- มี space ส่วนตัว

### ลักษณะที่สังเกตได้
- เกลียด micromanagement — "นายคุมทุก step เลยนะ"
- ชอบงาน freelance, remote, self-employed
- ต่อต้านกฎที่รู้สึกว่าไร้เหตุผล — "ทำไมต้องทำแบบนี้?"
- ชอบคำว่า "แล้วแต่คุณ", "ตามสบาย", "ไม่ต้องรีบ"
- มีความสุขเวลาได้เดินทางคนเดียว
- ตัดสินใจเร็วเมื่อรู้สึกว่ามีอิสระ

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "ทำงานที่ไหนก็ได้ใช่ไหม?" | ต้องการอิสระทางสถานที่ |
| "ขอ flexible hours ได้ไหม?" | ต้องการอิสระทางเวลา |
| "ไม่ต้องมาสั่งผมทุกอย่าง" | ต่อต้านการควบคุม |
| "ผมขอทำในแบบของผม" | ต้องการ autonomy |
| "วันนี้ขอ off ได้ไหม?" | ต้องการควบคุมตารางชีวิตตัวเอง |
| "ผมเบื่อระบบราชการ" | หงุดหงิดกับ bureaucracy |

### สถานการณ์ตัวอย่าง
> **คุณโจ อายุ 32** โปรแกรมเมอร์ฝีมือดี — ลาออกจากบริษัทใหญ่ทั้งที่เงินเดือนดี — เหตุผล: "ผมทนไม่ได้ที่ต้องขออนุมัติทุกอย่าง — อยากใช้ tool ใหม่ก็ต้องรอ 3 เดือน" — เขายอมรับเงินน้อยลงแต่ได้อิสระมากขึ้น

### ด้านมืด

- หนีความรับผิดชอบ → "อิสระ" = "ไม่ต้องรับผิดชอบ"
- โดดเดี่ยว — อิสระมากเกินไปจนไม่มีใคร

## 10. 🌈 ต้องการความหมายและจุดมุ่งหมาย (Purpose & Meaning)

> **"ฉันเกิดมาทำไม? ฉันจะทิ้งอะไรไว้ให้โลก?"**

### สิ่งที่ต้องการ
- รู้สึกว่าชีวิตมี meaning — ไม่ใช่แค่ตื่นมาทำงาน
- ทำงานที่ "ใช่" — สร้าง impact, ช่วยเหลือคนอื่น
- มีเป้าหมายที่ใหญ่กว่าตัวเอง
- spirituality, ศาสนา, ปรัชญาชีวิต

### ลักษณะที่สังเกตได้
- ถามคำถาม deep — "เราทำงานนี้ไปเพื่ออะไร?"
- ไม่โอเคกับการทำงานที่ไร้ความหมาย
- พูดถึง impact มากกว่าเงิน
- เปลี่ยนงานบ่อยเพราะ "ไม่ใช่"
- ชอบทำ volunteer, NGO, social enterprise
- มีอาการ "midlife crisis" — ตื่นมาคิดว่าชีวิตนี้เพื่ออะไร

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "งานนี้มันเปลี่ยนอะไรได้บ้าง?" | ต้องการ impact |
| "ผมทำงานนี้ไปเพื่ออะไร?" | ต้องการ meaning |
| "เงินไม่ใช่ทุกอย่าง" | ต่อต้าน materialism |
| "ผมอยากทำอะไรที่ทิ้งไว้ให้ลูกดู" | ต้องการ legacy |
| "รู้สึกว่างเปล่า" | ขาด purpose |
| "ผมอยากช่วยคน" | ต้องการ contribution |

### สถานการณ์ตัวอย่าง
> **พี่ตุ๊ก อายุ 40** — ลาออกจากงาน corporate เงินเดือน 6 หลัก — ไปเปิดร้านกาแฟเล็กๆ ที่จ้างคนพิการ — "ทุกเช้าที่ตื่นมาเห็นพนักงานยิ้มได้ — นั่นแหละคือเงินเดือนของฉัน" — เธอหา purpose เจอแล้ว

### ด้านมืด
- ตามหา purpose จนลืมปัจจุบัน — ชีวิตผ่านไปโดยไม่ได้อยู่กับมัน
- ดูถูกคนที่ทำงานเพื่อเงิน
- เปลี่ยน方向บ่อยจนไม่เหลืออะไร

## 11. ⚖️ ต้องการความยุติธรรมและความเท่าเทียม (Justice & Fairness)

> **"มันต้องแฟร์! ฉันไม่ยอมให้ใครเอาเปรียบ"**

### สิ่งที่ต้องการ
- ความยุติธรรม — กฎกติกาต้องเท่ากันทุกคน
- ไม่ถูกเอาเปรียบ, ไม่มีการเลือกปฏิบัติ
- คนผิดต้องถูกลงโทษ, คนถูกต้องได้รับความชอบธรรม
- transparency, accountability

### ลักษณะที่สังเกตได้
- อ่อนไหวมากกับความไม่เท่าเทียม — "ทำไมเขาถึงได้..."
- สู้เพื่อสิทธิ — ฟ้องร้อง, ร้องเรียน, whistleblow
- ถามหาเหตุผลของกฎ — "ทำไมถึงเป็นกฎ?"
- ใช้คำว่า "มันไม่แฟร์!", "มันไม่ถูกต้อง"
- เสียสละตัวเองเพื่อความถูกต้อง
- ติดตามข่าวความอยุติธรรมในสังคม

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "มันไม่แฟร์!" | รับรู้ถึงความไม่ยุติธรรม |
| "ทำไมเขาได้ แต่ฉันไม่ได้?" | ต้องการ equal treatment |
| "กฎข้อนี้มันใครเขียน?" | ต้องการ accountability |
| "ผมจะฟ้อง!" | ต้องการ justice |
| "คุณเลือกปฏิบัติ" | รับรู้ถึง discrimination |
| "ขอดูกฎหน่อย" | ต้องการ transparency |

### สถานการณ์ตัวอย่าง
> **น้องอาร์ม อายุ 19** — นักศึกษา — เพื่อนลอกข้อสอบแต่ได้คะแนนมากกว่าเขา — แทนที่จะลอกบ้าง เขากลับไปฟ้องอาจารย์ — "ผมไม่แคร์ว่าคะแนนจะต่ำ ขอแค่ให้มันยุติธรรม" — เขาไม่ได้อยากได้ A แต่อยากให้เกมนี้แฟร์

### ด้านมืด
- กลายเป็นคนขี้ฟ้อง — ไม่มีใครอยากทำงานด้วย
- มองโลกในแง่ร้าย — เห็นแต่ความอยุติธรรม
- ลืม compassion — ยึดติดกับกฎจนลืมคน

## 12. 🗂️ ต้องการความเป็นระเบียบและความแน่นอน (Order & Certainty)

> **"ฉันต้องรู้ว่าอะไรจะเกิดขึ้น เมื่อไหร่ ยังไง"**

### สิ่งที่ต้องการ
- predictability — รู้ล่วงหน้าว่าจะเกิดอะไรขึ้น
- กฎ กติกา ขั้นตอน ที่ชัดเจน
- routine, checklist, plan
- หลีกเลี่ยงความประหลาดใจ

### ลักษณะที่สังเกตได้
- ชอบทำ checklist — "ขอ list หน่อย"
- หงุดหงิดกับ last-minute changes
- วางแผนล่วงหน้านาน — จองตั๋ว 6 เดือน
- ใช้ planner, calendar, reminder
- ถาม "แล้วขั้นตอนต่อไปคืออะไร?"
- ตื่นตระหนกเมื่อแผนเปลี่ยน — "เดี๋ยว! เราไม่ได้ตกลงกันแบบนี้"

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "ขอเป็น checklist ได้ไหม?" | ต้องการ structure |
| "แล้วขั้นตอนต่อไปคือ?" | ต้องการ predictability |
| "เรามีกำหนดการไหม?" | ต้องการ certainty |
| "ส่ง agenda มาก่อนประชุม" | ต้องการเตรียมตัว |
| "เมื่อกี้เราไม่ได้ตกลงกันแบบนี้นะ" | หงุดหงิดกับความไม่แน่นอน |
| "ขอเวลาคิดก่อน" | ต้องการเวลา process |

### สถานการณ์ตัวอย่าง
> **คุณยุ้ย อายุ 33** — Project Manager — ก่อนประชุมทุกครั้งต้องส่ง agenda 24 ชม. — slide ต้องมี agenda, objective, expected outcome — เธอไม่ได้เรื่องมาก แต่ "การไม่มี agenda คือการเสียเวลา 1 ชม. แรกของประชุม"

### ด้านมืด
- Rigid — ไม่ยืดหยุ่นเมื่อสถานการณ์เปลี่ยน
- Obsessive — หมกมุ่นกับรายละเอียดจนไม่เห็นภาพใหญ่
- ควบคุมคนอื่นมากเกินไป

## 13. 🔍 ต้องการความอยากรู้อยากเห็นและประสบการณ์ใหม่ (Curiosity & Novelty)

> **"มีอะไรใหม่ๆ ให้ลองไหม? โลกนี้มีอะไรอีกตั้งเยอะ"**

### สิ่งที่ต้องการ
- ประสบการณ์ใหม่, สถานที่ใหม่, คนใหม่
- ทดลองสิ่งที่ไม่เคยทำ — adventure, travel
- ความตื่นเต้น, ความแปลกใหม่
- หลีกหนีความจำเจ — novelty seeking

### ลักษณะที่สังเกตได้
- เบื่อง่าย — เปลี่ยนงาน/งานอดิเรกบ่อย
- ตื่นเต้นกับของใหม่ — "ตัวนี้ออกใหม่นะ!"
- ชอบเที่ยว — passport เต็มไปด้วยตราประทับ
- ถามว่า "แล้วมีอะไรอีก?"
- ไม่ชอบ routine — "ทำแบบเดิมทุกวันมันน่าเบื่อ"
- กล้าลอง — ไม่กลัวความผิดพลาด

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "มีอะไรใหม่ๆ ไหม?" | novelty seeking |
| "น่าเบื่อจัง!" | ต่อต้าน routine |
| "ไปเที่ยวกันไหม?" (ถามทุกเดือน) | ต้องการ adventure |
| "ผมยังไม่เคยลองอันนี้เลย" | ตื่นเต้นกับสิ่งใหม่ |
| "เสาร์นี้ทำอะไรดี?" (เบื่ออยู่บ้าน) | ต้องการ stimulation |
| "มีที่ไหนที่ยังไม่เคยไปบ้าง?" | ต้องการ exploration |

### สถานการณ์ตัวอย่าง
> **พี่ต้อม อายุ 29** — Digital Nomad — ทำงานจาก laptop — เปลี่ยนประเทศทุก 3 เดือน — "อยู่ที่เดียวนานๆ แล้วรู้สึกเหมือนติดกรง" — เขาไม่ได้หนีอะไร แต่ "โลกนี้มีอะไรให้ดูอีกเยอะ"

### ด้านมืด
- ไม่มีราก — ไม่สามารถตั้งหลักที่ไหนได้นาน
- เปลี่ยน方向บ่อย — เริ่มหลายอย่าง ไม่จบสักอย่าง
- เสี่ยงเกินไป — ทำอะไรประมาทเพื่อความตื่นเต้น

## 14. 🛋️ ต้องการความสะดวกสบายและความสุขทางกาย (Comfort & Pleasure)

> **"ชีวิตมันต้องง่าย สบาย ไม่ต้องลำบาก"**

### สิ่งที่ต้องการ
- สะดวก — ไม่ต้องใช้ความพยายามมาก
- สบาย — ทางกาย (ที่นอนดี, แอร์เย็น) และทางใจ (ไม่เครียด)
- ความสุขทางประสาทสัมผัส — อาหารอร่อย, นวด, กลิ่นหอม
- convenience — one-click, delivery, automation

### ลักษณะที่สังเกตได้
- ยอมจ่ายแพงขึ้นเพื่อความสะดวก — Grab vs ขับเอง
- บ่นเรื่องความไม่สะดวก — "ทำไมต้องยุ่งยากขนาดนี้?"
- ใช้ service ที่ทำให้ชีวิตง่าย — แม่บ้าน, laundry, food delivery
- เลือกที่นั่งที่สบายที่สุด, ห้องที่เงียบที่สุด
- หลีกเลี่ยงงานที่ต้องใช้แรง
- ซื้อของที่ "ทำให้ชีวิตดีขึ้น" — เครื่องฟอกอากาศ, หมอน memory foam

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "มีวิธีที่ง่ายกว่านี้ไหม?" | ต้องการ convenience |
| "ขี้เกียจ" | ต้องการลด effort |
| "มี delivery ไหม?" | ไม่ต้องการ travel |
| "ขอห้องที่เงียบๆ" | ต้องการ comfort |
| "มีแบบที่นั่งดีๆ ไหม?" | ต้องการ physical comfort |
| "ไม่อยากปวดหัว" | ต้องการ peace of mind |

### สถานการณ์ตัวอย่าง
> **คุณเจมส์ อายุ 37** — สั่ง Grab ทุกมื้อ — ค่าส่ง 60-80 บาทต่อครั้ง — เดือนนึงหมดหลายพัน — "ผมไม่ได้ขี้เกียจนะ แต่เวลา 30 นาทีที่ใช้เดินทางไปกินข้าว ผมเอาไปทำงานได้เงินมากกว่า" — เขาซื้อ "เวลา" ด้วยเงิน

### ด้านมืด
- ขี้เกียจ — ไม่ยอมทำอะไรที่ต้องใช้ effort
- สุขนิยม — ตามใจตัวเองจนเสียสุขภาพ/การเงิน
- ไม่พัฒนา — อยู่ใน comfort zone ตลอด

## 15. 🎨 ต้องการความงามและสุนทรียภาพ (Beauty & Aesthetics)

> **"โลกนี้ต้องสวย ต้องมีรสนิยม ต้องดีไซน์ดี"**

### สิ่งที่ต้องการ
- ความสวยงาม — ทั้ง visual, sound, touch
- ดีไซน์ที่ดี — ไม่ใช่แค่สวย แต่ "ลงตัว"
- ศิลปะ, ดนตรี, วัฒนธรรม
- บรรยากาศที่สวยงาม — ร้านกาแฟสวยๆ, โรงแรมดีไซน์

### ลักษณะที่สังเกตได้
- วิจารณ์ดีไซน์ — "font นี้ไม่เข้ากันเลย"
- ถ่ายรูปองค์ประกอบ — มุมกาแฟ, พระอาทิตย์ตก, สถาปัตยกรรม
- อารมณ์เสียกับสิ่งที่ " ugly" — "ทำไม UI นี้ดูถูกจัง"
- ยอมจ่ายแพงเพื่อความสวย — ร้านอาหารแพงๆ เพราะ "บรรยากาศดี"
- มีสไตล์ชัดเจน — แต่งตัวมีเอกลักษณ์
- ใช้เวลาเลือกของนาน — เพราะ "มันต้องใช่"

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "สวยจัง!" | ตอบสนองทางอารมณ์ต่อความงาม |
| "ขอร้านบรรยากาศดีๆ" | ต้องการ aesthetic experience |
| "UI นี้แย่มาก" | หงุดหงิดกับ bad design |
| "มันดูถูกไปหน่อย" | ต้องการ refinement |
| "ขอดู collection ใหม่" | ตามหา beauty |
| "ใครออกแบบร้านนี้?" | สนใจใน creator |

### สถานการณ์ตัวอย่าง
> **คุณแพร อายุ 31** — เจ้าของร้านดอกไม้ — เลือกกระดาษห่อดอกไม้ 2 ชั่วโมง — "กระดาษผิดสี = ดอกไม้ดูถูกทันที" — เธอขาย "ความสวย" ความสวยต้อง perfect

### ด้านมืด
- Perfectionist — ไม่มีอะไรดีพอ
- เสียเงินเกินตัวเพื่อความสวย
- ดูถูกสิ่งที่ "ไม่สวย" จนลืม function

## 16. 🏛️ ต้องการสร้างมรดกและการมีส่วนร่วม (Legacy & Contribution)

> **"หลังจากฉันตายไป ฉันจะทิ้งอะไรไว้ให้โลก?"**

### สิ่งที่ต้องการ
- สร้างบางสิ่งที่จะคงอยู่ — ธุรกิจ, หนังสือ, มูลนิธิ
- ให้คนรุ่นหลัง — สอน, mentor, donate
- impact ระยะยาว — ไม่ใช่แค่ quick win
- รู้สึกว่า "ฉันมีส่วนทำให้โลกดีขึ้น"

### ลักษณะที่สังเกตได้
- พูดถึง "คนรุ่นต่อไป" — "ลูกหลานเราจะ..."
- บริจาค, สอน, mentor
- ทำงานหนักเพื่อสร้าง "สิ่งที่ยั่งยืน"
- ไม่สนใจ reward ระยะสั้น — มอง 10-20 ปี
- สร้าง system — ไม่ใช่แค่แก้ปัญหาเฉพาะหน้า
- ปลงกับเรื่องเล็กน้อย — เพราะมองภาพใหญ่

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "ผมอยากสร้างอะไรที่อยู่ต่อไปอีก 100 ปี" | ต้องการ legacy |
| "ลูกหลานเราจะได้ประโยชน์จากตรงนี้" | มองข้ามรุ่น |
| "ผมไม่ได้ทำเพื่อเงิน" | ต้องการ contribution |
| "ขอสอนน้องๆ หน่อย" | ต้องการ mentor |
| "ทิ้งอะไรไว้ให้สังคมบ้าง" | ต้องการ impact |
| "ผมไม่ต้องเป็นคนรับเครดิตก็ได้" | ปลงกับ ego |

### สถานการณ์ตัวอย่าง
> **อาจารย์สมหมาย อายุ 65** — เกษียณแล้วแต่สอนหนังสือฟรีทุกวันเสาร์ — "เงินเดือนผมพอแล้ว — แต่ความรู้ต้องไม่ตายไปกับผม" — เขาอยากให้ "ความรู้" เป็นมรดก

### ด้านมืด
- ละเลยปัจจุบันเพื่ออนาคต — ไม่ดูแลสุขภาพ
- บังคับให้คนอื่นทำตามวิสัยทัศน์ของตัวเอง
- เสียใจเมื่อ legacy ไม่เป็นไปตามที่หวัง

## 17. 🎭 ต้องการตัวตนและการแสดงออก (Identity & Self-Expression)

> **"ฉันเป็นใคร และฉันต้องแสดงความเป็นตัวเองออกมา"**

### สิ่งที่ต้องการ
- แสดงตัวตนที่แท้จริง — ไม่ต้องเสแสร้ง
- มีเอกลักษณ์ — "ฉันไม่เหมือนใคร"
- สร้าง personal brand
- ได้ทำในสิ่งที่สะท้อน "ตัวตน"

### ลักษณะที่สังเกตได้
- แต่งตัวมีเอกลักษณ์ — ไม่ตามแฟชั่น
- พูดถึง "ตัวตน" — "นี่แหละคือผม"
- ต่อต้านการถูกบอกว่าต้องเป็นอะไร — "คุณไม่ต้องมาบอกผม"
- แชร์ความเห็นส่วนตัวแรงๆ
- สร้าง content — blog, vlog, podcast
- ยอมเสียโอกาสเพื่อรักษาความเป็นตัวเอง

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "นี่แหละคือตัวผม" | ยืนยัน identity |
| "ผมไม่อยากเป็นแบบนั้น" | ต่อต้าน conformity |
| "ขอทำในสไตล์ของผม" | ต้องการ self-expression |
| "คุณไม่เข้าใจผม" | รู้สึกว่า identity ไม่ถูกมองเห็น |
| "ทำไมผมต้องเหมือนคนอื่น?" | ต่อต้าน norm |
| "งานนี้มันไม่ใช่ตัวผม" | รู้สึกว่าไม่ align กับ identity |

### สถานการณ์ตัวอย่าง
> **น้องไอซ์ อายุ 23** — TikToker — ครอบครัวอยากให้เป็นหมอ — เธอเลือกเป็น content creator — "หนูไม่ได้อยากดัง — หนูแค่อยากทำในสิ่งที่หนูเป็น" — รายได้น้อยกว่าหมอ แต่ "ได้เป็นตัวเอง"

### ด้านมืด
- ดื้อรั้น — ไม่ยืดหยุ่น
- ต่อต้านทุกอย่างที่ "ไม่ใช่ตัวเอง" — พลาดโอกาสดีๆ
- ใช้ "ตัวตน" เป็นข้ออ้างในการไม่พัฒนา

## 18. 💕 ต้องการความรักและความผูกพันลึกซึ้ง (Love & Deep Connection)

> **"ฉันอยากให้ใครสักคนรักฉันในแบบที่ฉันเป็น"**

### สิ่งที่ต้องการ
- ความรัก — romantic, familial, friendship
- deep connection — ไม่ใช่แค่รู้จัก แต่ "เข้าใจ"
- commitment, loyalty, trust
- รู้สึกว่า "มีคนที่รับเราได้ทั้งหมด"

### ลักษณะที่สังเกตได้
- ใช้เวลากับคนที่รัก — แม้จะยุ่งแค่ไหน
- เสียสละเพื่อความสัมพันธ์ — ยอมเปลี่ยนงาน ย้ายเมือง
- กลัวการถูกทอดทิ้ง — abandonment issue
- พูดถึงคนสำคัญในชีวิตบ่อย
- ให้อภัย — แม้จะเจ็บ
- มีความสุขที่สุดเมื่ออยู่กับ "คนที่ใช่"

### คำพูดที่ได้ยินแล้วรู้ว่าใช่
| คำพูด | แรงขับที่ซ่อนอยู่ |
|--------|-----------------|
| "กลับบ้านไปหาลูกก่อนนะ" | ครอบครัวมาก่อนสิ่งอื่น |
| "ผมทำทั้งหมดนี้เพื่อครอบครัว" | love = motivation |
| "คุณคือทุกอย่างของผม" | deep emotional investment |
| "ผมกลัวการอยู่คนเดียว" | กลัว isolation |
| "เขาไม่เข้าใจผมเลย" | ต้องการ emotional connection |
| "แค่อยากมีใครสักคน" | โหยหาความรัก |

### สถานการณ์ตัวอย่าง
> **คุณหมอไกร อายุ 40** — ศัลยแพทย์ — ปฏิเสธงานที่อเมริกา เงินเดือน 10 เท่า — "เงินซื้อเวลากลับมากอดลูกทุกวันไม่ได้" — เขาเลือก "ความรัก" มากกว่า "ความสำเร็จ"

### ด้านมืด
- Codependency — ไม่สามารถอยู่คนเดียวได้
- อดทนกับ toxic relationship มากเกินไป
- ละเลยตัวเองเพื่อคนอื่น
