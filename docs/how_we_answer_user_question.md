## 🎯 สรุป: 2 Paths

| Path | ใช้เมื่อ | ข้อดี |
|------|---------|-------|
| 🅰️ Search | รู้ว่าปัญหาคืออะไร อยากได้คำตอบเร็ว | ตอบทันที ไม่ต้องตอบคำถาม |
| 🅱️ Diagnosis | อยากได้ Action Plan ละเอียด ติดตามเคส | มีไทม์ไลน์, หลักฐาน, ติดตามผล |

### Human Drives ที่ใช้:

| Drive | ใช้ยังไง |
|-------|---------|
| 🛡️ Survival | "รีบแจ้งภายใน 24 ชม." — Loss Aversion |
| 📋 Certainty | บอกขั้นตอนชัดเจน 1→2→3 — ลดความกังวล |
| ⏰ Urgency | "ภายใน 1-3 ชม." "โอกาสได้คืน 60-70%" — FOMO |
| 🌟 Recognition | "คุณมีสิทธิ..." — empowerment |
