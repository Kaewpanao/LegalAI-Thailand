## ส่วนที่ 1: ภาพรวมแพลตฟอร์ม

### 1.1 LegalAI Thailand Citizen คืออะไร

**LegalAI Thailand Citizen** เป็นแพลตฟอร์มกฎหมายสำหรับประชาชนไทยที่ใช้ AI (DeepSeek) ในการวินิจฉัยปัญหากฎหมายเบื้องต้น ให้ข้อมูลสิทธิและขั้นตอนในการดำเนินการ โดย **ไม่ใช่การให้คำแนะนำทางกฎหมาย** (legal advice) แต่เป็นการให้ **ข้อมูลทางกฎหมาย** (legal information) เพื่อให้ประชาชนเข้าใจสิทธิของตนเอง

### 2.3 ระบบ Fear Calibration (ถามความรู้สึกก่อนวินิจฉัย)

ระบบจาก `lib/legal/fear-calibration.ts` ถามคำถาม: **"คุณรู้สึกยังไงกับเรื่องนี้?"** ก่อนเริ่ม diagnosis เพื่อปรับการตอบสนองให้ตรงกับอารมณ์ผู้ใช้

| ระดับ | ความรู้สึก | Urgency | Tone | Deadline |
|-------|-----------|---------|------|----------|
| 😰 **Panic** | กลัวมาก — ต้องทำอะไรสักอย่างเดี๋ยวนี้ | ทันที (24 ชม.) | Soothe (ปลอบใจ) | ทำทันที — อย่ารอ |
| 😟 **Urgent** | กังวล — อยากรู้ว่าต้องเริ่มจากตรงไหน | 1-3 วัน | Reassure (ให้กำลังใจ) | ควรทำภายใน 1-3 วัน |
| 🤔 **Concerned** | เป็นห่วง — อยากรู้สิทธิและเตรียมตัว | 1-2 สัปดาห์ | Guide (แนะนำ) | ควรทำภายใน 1-2 สัปดาห์ |
| 📋 **Planning** | วางแผน — ยังไม่รีบ แต่อยากรู้ไว้ก่อน | 1 เดือน | Inform (ให้ข้อมูล) | เตรียมพร้อม — ไม่ต้องรีบ |

ประโยชน์ของ Fear Calibration:
1. ปรับ urgency ของ action plan ให้ตรงกับความรู้สึก
2. เลือก tone ของข้อความ (ปลอบใจ, เร่งด่วน, ให้ข้อมูล)
3. ทำให้ AI ตอบสนองแบบ human-centric

### 3.4 ระบบ Merge Engine

ระบบใช้ `merge_fields_schema` (JSONB ใน document_templates) เพื่อให้ผู้ใช้กรอกข้อมูลเฉพาะจุด (ชื่อ, วันที่, จำนวนเงิน) แล้ว AI/Engine จะ merge เข้ากับเทมเพลต:

```
เทมเพลต (Markdown/Text) + Merge Fields จากผู้ใช้
   → AI เติมข้อมูลในช่องว่าง
   → ตรวจสอบความถูกต้อง (Guardrails)
   → Export เป็น PDF / DOCX / TXT
```

### 3.5 Export Formats

- **PDF** — สำหรับการพิมพ์และยื่นต่อหน่วยงาน
- **DOCX** — แก้ไขต่อได้ใน Microsoft Word
- **TXT** — plain text สำหรับใช้ในระบบอื่น

### 3.6 ระบบค้นหาเอกสาร

มีระบบค้นหาจาก `lib/documents/categories.ts` ด้วย keyword mapping:
- พิมพ์ "เช่า" → แนะนำหมวด rental_lease
- พิมพ์ "กู้" → แนะนำหมวด loans_finance
- พิมพ์ "nda" → แนะนำหมวด employment_hr
- พิมพ์ "pdpa" → แนะนำหมวด commercial_trade

สามารถกรองด้วย `free` / `paid` / `all` ตามแพ็กเกจผู้ใช้

### 3.7 Document Generation API Flow

```
POST /api/documents/generate → {
  templateId, mergeFields → AI Generator → rendered document
  → เก็บใน Supabase Storage → ตรวจสอบ guardrails
  → ส่งกลับให้ผู้ใช้พร้อม download link
}
```

| 7 | **ต้องมี disclaimer ทุกผลลัพธ์ AI** | P1: "AI อาจผิดพลาด — ตรวจสอบข้อมูลกับผู้เชี่ยวชาญก่อนดำเนินการ" |

### 6.2 Banned Patterns (Regular Expressions)

ระบบตรวจจับ pattern ต้องห้ามโดยอัตโนมัติ:

| กฎ | Patterns |
|-----|----------|
| no-legal-advice | `คุณควร(ทำ|ฟ้อง|ยื่น|เรียก|เรียกร้อง)`, `แนะนำให้(คุณ|ท่าน)`, `ทางที่ดี(ที่สุด|)คือ` |
| no-outcome-prediction | `(มีโอกาส|โอกาส)ชนะ\s*\d+%`, `ชนะ(คดี|แน่)`, `ได้เงิน(คืน|)แน่` |
| no-lawyer-ranking | `ทนาย(ที่|คนนี้)(ดี|เก่ง)(ที่สุด|มาก)`, `แนะนำ(ให้เลือก|)ทนาย(คนนี้|ท่านนี้)` |
| no-court-filing | `เรา(จะ|ได้)ยื่น(เอกสาร|คำร้อง|คำฟ้อง)` |
| pii-redaction | `\d{13}` (Thai ID), `0\d{1,2}[\s-]?\d{3}[\s-]?\d{4}` (Thai phone) |

### 6.4 Standard Disclaimer

```
⚠️ ข้อควรทราบ:
• ข้อมูลนี้เป็นข้อมูลกฎหมายทั่วไป (legal information) ไม่ใช่คำแนะนำทางกฎหมาย (legal advice)
• AI อาจมีข้อผิดพลาด — ควรตรวจสอบกับทนายหรือผู้เชี่ยวชาญก่อนดำเนินการ
• เราไม่รับประกันผลลัพธ์ — แต่ละคดีมีปัจจัยเฉพาะ
• ข้อมูลของคุณได้รับการปกป้องตาม PDPA
```

### 6.5 Database-level Security (RLS)

จาก `db/schema.ts` — ทุกตารางเชื่อมโยงกับ `ownerId` (auth.uid()) หรือ `case_members`:
- ทุกตารางมี RLS enabled
- `audit_events` — client read-only (no insert/update/delete)
- Evidence storage bucket — private (no public read path)
- Service role key never exposed client-side
- Browser client ใช้ anon key เท่านั้น

### 8.5 Flow การใช้งานหลัก

```
1. ผู้ใช้เข้า / (Home)
   ├─ ยังไม่มีบัญชี → /auth/signin → /onboarding
   └─ มีบัญชีแล้ว → Dashboard

2. เริ่มวินิจฉัย: / → /diagnosis
   → เลือกหมวดกฎหมาย (12 หมวด)
   → Fear Calibration (ถามความรู้สึก)
   → ตอบคำถาม 4 ข้อ
   → POST /api/ai/diagnosis
   → /analysis/[caseId] (ผลลัพธ์)

3. จัดการเคส: /cases
   → ดูเคส → /cases/[caseId]/evidence
   → /cases/[caseId]/timeline

4. สร้างเอกสาร: /documents
   → เลือกหมวด → กรอก merge fields
   → POST /api/documents/generate
   → Download PDF/DOCX/TXT

5. คำนวณภาษี: Tax Calculator (ใน profile/dashboard)
   → กรอกรายได้ + ค่าลดหย่อน
   → Progressive calculation → ผลลัพธ์

6. ปรึกษาทนาย: /lawyers
   → เลือกทนาย → POST /api/consultations
```
