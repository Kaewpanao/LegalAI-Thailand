## 🔴🔵 Analysis: What Went Well vs Gaps

### ✅ MATCH — Platform Handles Well:

| Element | How |
|---------|-----|
| 🎯 Category mapping | `defamation` → "ภาพหลุด/แอบถ่าย" ตรงเป๊ะ |
| ⏰ Urgency | "ภายใน 3 เดือน" ในคำถาม when — loss aversion |
| 📸 Evidence | แคปหน้าจอ + URL + พยาน — ครบ |
| ⚖️ Laws | ม.326-328, พ.ร.บ.คอมพิวเตอร์ |

### ❌ GAPs Found:

| # | Gap | Impact |
|---|-----|--------|
| 1 | **ไม่มี "Telegram" ใน platform options** | ผู้ใช้ต้องเลือก "เว็บบอร์ด" — ไม่แม่น |
| 2 | **ไม่ถาม "ใครเป็นคนโพสต์"** (แฟนเก่า vs คนแปลกหน้า) | ซึ่งมีผลทางกฎหมายต่างกัน |
| 3 | **ไม่มี mention StopNCII.org** | สำคัญมากสำหรับ revenge porn |
| 4 | **ไม่ถาม "มีกี่คนเห็น"** (กลุ่มลับ 30 คน vs สาธารณะ) | มีผลต่อโทษ (ม.328 = โฆษณา) |
| 5 | **ไม่มี trauma-informed guidance** | "อย่าคุยกับแฟนเก่า" "เหยื่อไม่ผิด" |
