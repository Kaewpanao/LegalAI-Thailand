## 🧠 ตารางที่ 1: หลักการจิตวิทยาการซื้อ 8 ข้อ

| หลักการ | แปลเป็นภาษาคน | ตัวอย่างในชีวิตจริง |
|---------|-------------|-----------------|
| **Loss Aversion** (กลัวเสีย > อยากได้) | คนเรากลัวการ "เสียอะไร" มากกว่าอยาก "ได้อะไร" ถึง 2 เท่า! | "ถ้าคุณไม่ฟ้องภายใน 7 วัน คุณจะหมดสิทธิ์เรียกเงินคืน" — ประโยคนี้ทำให้คนรีบทำ เพราะกลัวเสียสิทธิ์ |
| **Social Proof** (คนอื่นใช้ → เราก็ใช้) | เวลาไม่แน่ใจ เราจะดูว่าคนอื่นทำอะไร แล้วทำตาม | ร้านอาหารคนต่อคิวยาว = น่าอร่อย / "มีคนใช้แก้ปัญหานี้สำเร็จ 50,000 คน" = น่าเชื่อถือ |
| **Anchoring** (ราคาแรกติดตา) | ราคาแรกที่เราเห็นจะกลายเป็น "ไม้บรรทัด" วัดว่าราคาอื่นถูกหรือแพง | เห็นป้าย "เคย 1,990 ลดเหลือ 990" → เราคิดว่า "ถูกจัง" ทั้งที่ 990 อาจเป็นราคาจริงตลอด |
| **Reciprocity** (ได้ฟรี → อยากตอบแทน) | พอมีคนให้อะไรเราฟรี เราจะรู้สึก "เป็นหนี้" และอยากตอบแทน | ได้ทดลองใช้ฟรี 7 วัน → พอหมด Trial ก็รู้สึกผิดถ้าไม่จ่ายต่อ |
| **Framing Effect** (วิธีพูดเปลี่ยนการตัดสินใจ) | เรื่องเดียวกัน แต่พูดคนละแบบ ทำให้คนตัดสินใจต่างกัน | "เนื้อ 90% ไร้ไขมัน" vs "เนื้อมีไขมัน 10%" — ความหมายเดียวกัน แต่แบบแรกขายดีกว่า |
| **Endowment Effect** (ของฉัน = มีค่า) | พอรู้สึกว่าเป็นเจ้าของแล้ว จะให้ค่ามากกว่าตอนยังไม่ใช่ของเรา | ลองขับรถแล้วรู้สึกว่า "นี่มันรถฉัน" → ยอมจ่ายแพงขึ้น |
| **Scarcity** (ของหายาก = น่ามี) | อะไรที่ดูเหมือนกำลังจะหมด หรือมีน้อย → คนอยากได้มากขึ้น | "ที่นั่งเหลือ 2 ที่สุดท้าย!" / Nike Dunk Limited Edition |
| **Decoy Effect** (ตัวเลือกหลอก) | เพิ่มตัวเลือกที่ "ตั้งใจให้ดูแย่" เพื่อให้อีกตัวเลือกดูดีขึ้น | Popcorn: Small 100฿ / Medium 150฿ / Large 160฿ → Large ดู "คุ้มสุด" ทั้งที่ Medium ก็พอแล้ว |

### 🎯 ทำไมถึงสำคัญกับ LegalAI?
- **Loss Aversion** → เตือน deadline ฟ้องร้อง กระตุ้นให้คนรีบจัดการ
- **Social Proof** → โชว์จำนวนคนที่แก้ปัญหาสำเร็จ สร้างความมั่นใจ
- **Reciprocity** → ให้ diagnosis ฟรี → คนอยากจ่ายต่อ
- **Framing** → ใช้คำว่า "แผนปฏิบัติการ" แทน "คำปรึกษากฎหมาย" เพราะคนไทยกลัวทนาย

## 🧪 ตารางที่ 2: A/B Test Ideas (การทดลองแบบวิทยาศาสตร์)

| Test | แปล | ทำไมต้องทดสอบ |
|------|------|-------------|
| **Fear vs. Hope** | ทดสอบระหว่าง "ถ้าคุณไม่ทำอะไร...จะเสียสิทธิ์" (กลัว) กับ "ทางออกของคุณคือ..." (ความหวัง) | อยากรู้ว่าคนไทยกลัวหรือมีความหวังแล้วลงมือทำมากกว่ากัน |
| **Social Proof on/off** | มี vs ไม่มี ตัวเลข "X คนใช้แก้ปัญหานี้" บนหน้าเว็บ | ดูว่าตัวเลข social proof ช่วยเพิ่มความมั่นใจให้คนกดสมัครจริงไหม |
| **Decoy Pricing** | เพิ่มแพ็กเกจราคากลางที่ "ตั้งใจให้ดูไม่คุ้ม" เพื่อดันให้อีกแพ็กดูดี | ร้านไอติม: เล็ก 50 / กลาง 90 / ใหญ่ 100 → ใหญ่ดูถูกสุด |
| **Urgency Timer** | แสดงจำนวน Slot ทนายที่เหลือ + เวลาหมด | "เหลือทนายว่าง 2 ท่าน ราคาพิเศษหมดใน 3 ชม." → เร่งให้ตัดสินใจ |

### 🎯 A/B Test คืออะไร?
คือการทดลอง 2 แบบ (A กับ B) กับคนใช้จริง แล้วดูว่าแบบไหนได้ผลดีกว่ากัน — เหมือนแข่งกันว่าโฆษณาแบบไหนคนคลิกเยอะกว่า

## 👥 ตารางที่ 3: จิตวิทยากลุ่ม — แต่ละกลุ่มคิดไม่เหมือนกัน

| กลุ่ม | พฤติกรรมกลุ่ม | ตัวอย่าง |
|------|-------------|---------|
| **B2C ทั่วไป** (คนธรรมดา) | Herd Behavior + FOMO | "เพื่อนบ้านฟ้องแล้วได้เงินคืนนะ เราต้องทำบ้าง" / กลัวตกขบวน |
| **SME** (เจ้าของธุรกิจเล็ก) | Tribe + Conformity | "ร้านอื่นในสมาคมเขาใช้โปรแกรมนี้กันหมดแล้ว" |
| **B2B2C / HR** (พนักงาน) | Social Identity | "บริษัทเราดูแลพนักงานนะ มีสวัสดิการกฎหมายให้ด้วย" |
| **Insurance** (บริษัทประกัน) | Risk Aversion | "เราต้องลดความเสี่ยง ไม่งั้นขาดทุน" |
| **Government** (หน่วยงานรัฐ) | Legitimacy | "หน่วยงานอื่นใช้แล้ว เวิร์ค! เราต้องใช้บ้าง" |
| **Dataset Buyers** (คนซื้อข้อมูล) | Social Comparison | "AI คู่แข่งใช้ข้อมูลชุดนี้ accuracy 95% เราต้องใช้บ้าง" |

### 🎯 ศัพท์เทคนิคอธิบาย:
- **Herd Behavior** = พฤติกรรมตามฝูง — คนทำตามคนส่วนใหญ่ (เหมือนแกะในฝูง)
- **FOMO** = Fear Of Missing Out — กลัวตกเทรนด์ กลัวพลาด
- **Tribe Mentality** = จิตวิทยาเผ่า — คนอยากอยู่ในกลุ่ม มีพวกเดียวกัน
- **Conformity** = การคล้อยตาม — อยากทำตัวให้เหมือนคนอื่นในกลุ่ม
- **Social Identity** = ตัวตนทางสังคม — เราอยากให้คนอื่นมองเรายังไง ("ฉันทำงานบริษัทที่ดูแลพนักงานดี")

## 👤 ตารางที่ 5-9: Consumer Segments (5 กลุ่มลูกค้า)

### ศัพท์ที่ใช้ในทุกตาราง Segments:

| คำศัพท์ | แปล | ตัวอย่าง |
|---------|------|---------|
| **JTBD (Jobs To Be Done)** | งานที่ลูกค้าจ้างผลิตภัณฑ์มาทำ | "ฉันไม่ได้อยากได้สว่าน — ฉันอยากได้รูบนผนัง" — LegalAI ไม่ได้ขาย AI แต่ขาย "การแก้ปัญหากฎหมาย" |
| **Demographic** | ข้อมูลประชากร | อายุ เพศ รายได้ การศึกษา |
| **Psychographic** | จิตวิทยา ไลฟ์สไตล์ | "คนนี้ชอบเสี่ยง" vs "คนนี้ชอบความมั่นคง" |
| **Pain Points** | จุดเจ็บปวด — ปัญหาที่ทำให้ลูกค้าทนไม่ไหว | "ไม่รู้จะเริ่มฟ้องยังไง" / "กลัวค่าทนายแพง" |
| **Buying Trigger** | ชนวนที่ทำให้ตัดสินใจซื้อ | โดนโกง → รีบหาวิธีฟ้อง |
| **Decision Journey** | เส้นทางก่อนซื้อ | Google → อ่าน → เช็คราคา → ซื้อ |
| **Willingness to Pay (WTP)** | ความเต็มใจจ่าย — จ่ายเท่าไหร่ถึงรู้สึก "คุ้ม" | "99-299 บาทสำหรับแก้ปัญหา 5,000 บาท — คุ้ม!" |
| **Retention** | การกลับมาใช้ซ้ำ | คนไข้กลับมาหาหมอคนเดิม |
| **Churn** | เลิกใช้ — ตรงข้ามกับ Retention | "ใช้ครั้งเดียว ไม่กลับมาอีก" |

### 🟢 Segment 1: "สมชาย" — คนธรรมดามีปัญหากะทันหัน
> **Pain:** ถูกโกงออนไลน์ 5,000 บาท → ไม่รู้เริ่มยังไง → กลัวค่าทนายแพงกว่าค่าเสียหาย
> **สิ่งที่ LegalAI ทำให้:** บอก step-by-step ว่าต้องทำอะไร → แค่ 99-299 บาท

### 🟡 Segment 2: "คุณนภา" — เจ้าของ SME
> **Pain:** โดนเบี้ยวเงิน 300,000 — ไม่มีแผนกกฎหมาย — จ้างทนายทีละ 50,000
> **สิ่งที่ LegalAI ทำให้:** จัดการเอกสาร ติดตาม deadline 1,000-3,000/เดือน = ถูกกว่าจ้างทนาย 10 เท่า

### 🔵 Segment 3: "คุณเมย์" — พนักงานใช้ผ่าน HR
> **Pain:** อยากให้ทนายดูสัญญาซื้อคอนโด แต่ไม่อยากให้ HR รู้เรื่องเงินส่วนตัว
> **สิ่งที่ LegalAI ทำให้:** ระบบ Privacy Firewall — บริษัทจ่าย แต่ไม่เห็นเนื้อหาคดี

### 🟣 Segment 4: Insurance
> **Pain:** บริษัทประกันเสียเงินค่าดำเนินการเคลมเยอะ ใช้เวลานาน
> **สิ่งที่ LegalAI ทำให้:** AI จัดการเคลม → เร็วขึ้น ถูกลง

### 🟤 Segment 5: Government
> **Pain:** เรื่องร้องเรียนกองท่วม เจ้าหน้าที่ไม่พอ ประชาชนรอเป็นปี
> **สิ่งที่ LegalAI ทำให้:** API คัดกรองเรื่องอัตโนมัติ → ลดภาระเจ้าหน้าที่

## 📈 ตารางที่ 10-11: SWOT Analysis (วิเคราะห์จุดแข็ง-จุดอ่อน)

### SWOT คืออะไร?
| ตัวอักษร | ความหมาย | คำถาม |
|----------|---------|--------|
| **S** = Strengths | จุดแข็ง — เราทำอะไรได้ดี | "เรามีอะไรที่คนอื่นไม่มี?" |
| **W** = Weaknesses | จุดอ่อน — เรายังพลาดตรงไหน | "อะไรที่เรายังสู้คนอื่นไม่ได้?" |
| **O** = Opportunities | โอกาส — อะไรกำลังจะเกิดขึ้นที่ดีกับเรา | "เทรนด์อะไรที่เราจะเกาะไปโต?" |
| **T** = Threats | ภัยคุกคาม — อะไรที่อาจทำให้เราเจ๊ง | "ใครจะมาแย่งตลาดเรา?" |

### ตัวอย่าง SWOT ที่เข้าใจง่าย:
- **S:** LegalAI มี "Legal Dataset" ที่ผ่านการตรวจสอบโดยผู้เชี่ยวชาญ → Google ทำไม่ได้
- **W:** ยังไม่มีใครรู้จักแบรนด์เลย → Day 1 ไม่มีคนเข้าเว็บ
- **O:** รัฐบาลไทยกำลังผลักดัน Digital Government → โอกาสขาย API ให้รัฐ
- **T:** ถ้า OpenAI ทำ Legal AI ไทย → คู่แข่งโคตรใหญ่

## 🏆 ตารางที่ 12: Porter's Five Forces (5 แรงกดดันทางการแข่งขัน)

### Porter's Five Forces คืออะไร?
คิดค้นโดย Michael Porter — เป็นเครื่องมือวิเคราะห์ว่า "ธุรกิจนี้แข่งขันกันดุเดือดแค่ไหน" ถ้า 5 แรงนี้สูง = ตลาดโหด = ทำกำไรยาก

| แรง | แปลเป็นภาษาคน | LegalAI ประเทศไทย |
|-----|-------------|-----------------|
| **คู่แข่งปัจจุบัน** | ในตลาดนี้มีใครบ้าง? เขาดุกันแค่ไหน? | 🟡 ยังไม่มีใครทำครบวงจร — ดี! |
| **คู่แข่งหน้าใหม่** | มีใครจะกระโดดเข้ามาแข่งง่ายไหม? | 🟡 ถ้ามีแค่ AI ธรรมดา = เข้าง่าย แต่ถ้ามี Dataset + ผู้เชี่ยวชาญ = เข้ายาก |
| **อำนาจต่อรองของซัพพลายเออร์** | คนขายของให้เราขึ้นราคาได้ไหม? | 🟢 LLM มี OpenAI, Google, DeepSeek ให้เลือก — ต่ำ |
| **อำนาจต่อรองของลูกค้า** | ลูกค้าต่อรองราคาได้แค่ไหน? | 🟡 คนทั่วไปมีทางเลือกอื่น (ไม่ทำอะไรเลย) = อำนาจสูง |
| **สินค้าทดแทน** | มีอะไรใช้แทนผลิตภัณฑ์เราได้บ้าง? | 🔴 อันตราย! "ไม่ทำอะไรเลย" คือคู่แข่งที่ใหญ่ที่สุด |

## ✅ ตารางที่ 15: Product-Market Fit (PMF) Assessment

### PMF คืออะไร?
Product-Market Fit = "ผลิตภัณฑ์เราตรงกับความต้องการของตลาดจริงไหม?"

| เกณฑ์ | แปล | ตัวอย่าง |
|-------|------|---------|
| Problem exists? | ปัญหามีจริงไหม? | คนไทยโดนโกงออนไลน์ทุกวัน = มีจริง ✅ |

### 🎯 3 ศัพท์วัฒนธรรม:
- **Collectivist** = สังคมที่คนตัดสินใจร่วมกันเป็นกลุ่ม (ตรงข้ามกับ Individualist = ตัดสินใจเอง)
- **High Power Distance** = สังคมที่คน "เกรงใจ" ผู้มีอำนาจ/อาวุโส (เด็กไม่เถียงผู้ใหญ่)
- **Trust deficit** = การขาดความไว้วางใจ — คนไทยผ่านประสบการณ์แย่ๆ กับระบบราชการมาจน "ไม่เชื่อ" อะไรง่ายๆ

## 📝 สรุปสั้นๆ ให้เข้าใจใน 1 นาที

1. **คนซื้อเพราะกลัว** (Loss Aversion) มากกว่าซื้อเพราะอยากได้ → ต้องบอกว่าถ้าไม่ทำอะไรจะเกิดอะไรขึ้น
2. **คนดูว่าคนอื่นทำอะไร** (Social Proof) → ต้องโชว์ว่าใครใช้แล้วสำเร็จบ้าง
3. **LINE คือทุกอย่างของคนไทย** → อย่าทำแค่เว็บ
4. **"ไม่ทำอะไรเลย" คือคู่แข่งที่อันตรายที่สุด** — ไม่ใช่ทนาย ไม่ใช่ AI
5. **Legal Dataset คือป้อมปราการ** — ถ้าสร้างก่อนและคุณภาพดี คู่แข่งลอกไม่ได้
