## Overview

This document catalogs all common Thai legal documents needed for **proactive/transactional** use — contracts, agreements, registrations, and forms that Thai citizens and businesses **want** to create (not reactive problem-driven documents like lawsuits or complaints). Each entry includes:

- **Document name in Thai** (official name used by Thais)
- **English equivalent name**
- **Use case** — when and why people need it
- **Government agency** involved (if any)
- **Auto-generation feasibility** — how well LegalAI's merge-field system can produce it
  - ✅ **HIGH** — pure merge fields, no registration required
  - 🟡 **MEDIUM** — needs some customization or specific formatting
  - ⬜ **LOW** — requires government form specificity, better done by lawyer

### Merge Field Architecture
Each document template should support:
- **Party fields**: name, address, ID number, tax ID, phone, email
- **Property fields**: title deed number, land plot number, area, address, Chanote/Nor Sor type
- **Financial fields**: amount, currency, interest rate, payment schedule, bank account
- **Date fields**: effective date, expiration date, renewal date
- **Conditional blocks**: optional clauses activated by boolean flags (e.g., "include non-compete", "include guarantee", "include witness signatures")
- **Bilingual output**: every document should generate in Thai (primary) with optional English translation side-by-side
