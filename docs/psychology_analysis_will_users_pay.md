# 🧠 Psychology Analysis: Will Users Pay?

> คำถาม: User จะอยากจ่ายตังค์มั้ย? ควรเสียเงินที่ขั้นตอนไหน?

---

## 📊 Analysis Summary

| คำถาม | คำตอบ |
|--------|-------|
| User จะจ่ายมั้ย? | ✅ **จ่าย** — แต่ต้องปรับ monetization gate |
| จ่ายตอนไหน? | ⚠️ **Phase 3-4** — ไม่ใช่ Phase 5 |
| Free ให้อะไร? | 🔧 **ต้องลด** — ตอนนี้ให้เยอะเกิน |

---

## 🔴 ปัญหา: Free Tier ให้เยอะเกินไป

### ปัจจุบัน:

```
🆓 FREE (Phase 1-5):
   ✅ เข้าใจปัญหา
   ✅ รู้สิทธิ
   ✅ รู้ศาล + ที่อยู่ + เบอร์
   ✅ รู้เอกสาร 12 รายการ
   
🔒 PAID (Phase 6-8):
   📄 คำฟ้อง + คำร้อง
   🏛️ ขั้นตอนในศาล
```

### 🧠 Psychological Problem:

| Principle | What Happens | Risk |
|-----------|-------------|------|
| 🎓 **Competence Drive** | "รู้ศาล รู้เอกสาร — ฉันทำเองได้!" | User รู้สึก empowered → **ไม่จ่าย** |
| 📋 **Information Satiation** | ได้ข้อมูลครบแล้ว 5 phases | "ก็รู้หมดแล้วนี่นา" → **ไม่จ่าย** |
| 🛡️ **DIY Illusion** | อ่านแล้ว "รู้สึก" ว่าทำได้ | แต่ทำจริงไม่ได้ → หงุดหงิด → **เลิกใช้** |
| 💸 **Anchoring** | เห็นฟรีเยอะ → คิดว่า paid ต้องแพง | "299 สำหรับแค่เอกสาร?" → **ไม่คุ้ม** |

### 📊 22 Human Drives Analysis:

| Drive | Free Tier Triggers | Impact on Pay |
|-------|-------------------|:---:|
| 🎓 Competence | ✅ "ฉันรู้แล้ว!" | 🔴 ลด — รู้สึกไม่ต้องพึ่งใคร |
| 🕊️ Autonomy | ✅ "ฉันทำเองได้" | 🔴 ลด — ไม่อยากให้คนอื่นมาทำให้ |
| 📋 Certainty | ✅ รู้ศาล รู้เอกสาร | 🔴 ลด — ความไม่แน่นอนหายไป |
| 🛡️ Survival | ⚠️ "แต่ทำเอกสารไม่เป็น" | 🟢 เพิ่ม — กลัวทำผิด |
| ⏰ Loss Aversion | ⚠️ "เสียเวลา 5 phases แล้ว" | 🟢 เพิ่ม — sunk cost |
| 💰 Benefit | ⚠️ "299 vs 30,000 ทนาย" | 🟢 เพิ่ม — perceived value |

> 🔴 **4 negative / 3 positive** — Free tier ใหญ่เกิน ทำให้แรงจูงใจจ่ายตังค์ลดลง

---

## 🟢 ทางแก้: ปรับ Monetization Gate

### ✅ แนะนำ — Gate ที่ Phase 3 (และเพิ่ม "Pain Point" ให้ชัด)

```
🆓 FREE (Phase 1-3):
   1. 🎯 เข้าใจปัญหา — "บ้านโดนงัด" → compound crime+insurance
   2. ⚖️ รู้สิทธิ — "คุณฟ้องได้ 3 ข้อหา โทษจำคุก 1-7 ปี"
   3. 🛤️ เลือกแนวทาง — ฟ้องเอง / ทนาย / ไกล่เกลี่ย
   
   ═══════════ 🔒 PAYWALL ═══════════
   
   "อยากรู้ว่าต้องไปศาลไหน? ต้องใช้เอกสารอะไร?
    แค่ 299 — เราบอกทุกขั้นตอนจนคุณทำเองได้"
   
🔒 PAID — Action Pack ฿299:
   4. 📍 รู้ศาล + วิธีเดินทาง + แผนที่
   5. 📄 เช็คลิสต์เอกสาร 12 รายการ + วิธีหาแต่ละอย่าง
   6. 🔧 คำฟ้อง + คำร้อง — AI สร้างให้
   7. 🏛️ ขั้นตอนในศาล — เคาน์เตอร์ไหน ถามใคร พูดอะไร

🔒 PAID — Case Plus ฿999:
   8. 📊 ติดตามคดี + ปรึกษาทนาย
```

### 🧠 Why This Works:

| Principle | Mechanism |
|-----------|----------|
| 🎣 **Curiosity Gap** | รู้สิทธิแล้ว → "แล้วต้องไปศาลไหน?" → ต้องจ่ายถึงจะรู้ |
| ⏰ **Sunk Cost** | ลงทุน 3 phases แล้ว — "เสียดาย มาต่ออีกนิด" |
| 😰 **Fear of Mistakes** | "รู้สิทธิ แต่กลัวทำผิดขั้นตอน" → จ่ายเพื่อความมั่นใจ |
| ⚓ **Anchoring** | "299 vs 30,000 ทนาย" → ชัดเจนว่าคุ้ม |
| 🎁 **Reciprocity** | ได้ของฟรี 3 phases → รู้สึกติดค้าง → อยากตอบแทน |
| 🏆 **Goal Gradient** | ใกล้ถึงเป้าหมายแล้ว (อีก 4 phases) → อยากไปให้สุด |

### 💡 Key Insight — "Pain Point" ต้องอยู่ที่ Gate:

| Wrong Gate (Phase 5) | Right Gate (Phase 3) |
|---------------------|---------------------|
| "รู้ศาล รู้เอกสารแล้ว — จ่ายทำไม?" | "รู้สิทธิแล้ว — แต่ไม่รู้ต้องไปศาลไหน!" |
| Curiosity = SATISFIED | Curiosity = PEAK |
| Pain = ต่ำ (รู้ทุกอย่างแล้ว) | Pain = สูง (ยังไม่รู้ขั้นตอน) |
